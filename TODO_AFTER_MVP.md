# QANI? - Post-MVP Roadmap (TODO_AFTER_MVP.md)

This file documents future enhancements and features planned beyond the initial MVP scope.

---

## 1. Gamification & Rewards
- [ ] **Streak Freeze Items**: Allow users to earn or purchase 1-day streak freezes.
- [ ] **Badges & Trophies**: Unlock visual badges for milestone achievements (e.g., 7-day streak, 30-day streak, top 1% fast responder, group champion).
- [ ] **Leaderboards**: Regional (city/university) and monthly leaderboards.

## 2. Advanced Social & Groups
- [ ] **Group Streak**: Shared team streak counter for private groups (if all members complete today's challenge, team streak increases).
- [ ] **Challenge Suggestions**: Group members can vote on tomorrow's custom group challenge.
- [ ] **Direct Mentions & Video Reactions**: Ability to record a video reaction response to a friend's challenge video.

## 3. Media & Processing Enhancements
- [ ] **FFmpeg Serverless Worker Cluster**: Scale video processing to dedicated AWS Lambda / GCP Cloud Run jobs.
- [ ] **AI Safety Filter**: Auto-flag NSFW or inappropriate content before manual admin moderation using Cloud Vision / Video Intelligence API.
- [ ] **Watermarking**: Auto-overlay "QANI?" logo and user's handle on shared videos.

## 4. Telegram Bot Integration & Push Notifications
- [ ] **Automated Reminders**: Send Telegram bot push notification 2 hours before challenge deadline if streak is at risk.
- [ ] **Friend Alert**: Notify users via bot when an invited friend submits today's video.

## 5. Monetization & Brand Partnerships
- [ ] **Sponsored Challenges**: Branded daily challenges with official sponsor banners (e.g. "Anorbank challenge: 10 soniyada taklifingni ayt").
- [ ] **Telegram Stars Integration**: Purchase custom video filters or badge customizations using Telegram Stars.
